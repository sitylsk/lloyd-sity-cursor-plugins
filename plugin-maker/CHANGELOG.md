# Changelog

## 1.1.0 — 2026-09-17

- Renamed the plugin identity from `grok-plugin-maker` to **plugin-maker** (Plugin Maker)
- Plugin factory: scaffold **any** marketplace plugin (any topic, any publisher)
- Simple vs Advanced starter choice (`choose-plugin-starter`) mapped to official `starter-simple` / `starter-advanced`
- Expanded `create-plugin-from-template` interview + real-file scaffold
- Manifest/validate skills cover optional hooks, MCP, agents, and commands without requiring them for Simple

## 1.0.0 — 2026-09-17

- Initial release by Lloyd Sity
- Skills: `create-plugin-from-template`, `customize-plugin-manifest`, `validate-and-submit-plugin`
- Rule: plugin-authoring conventions for Cursor marketplace plugins
- Based on https://github.com/cursor/plugin-template
